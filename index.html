1.1 · Convolution from scratch

The four-loop version loops over each image and kernel row and column. The two-loop version uses one loop for the image and one for the kernel, finding the row with integer division by the width and the column by taking the remainder.

The image is zero-padded around the borders. For an odd kernel length l, the padding on each side is l // 2.

The box filter is a 9 × 9 array with every value equal to 1/81. The difference filters are Dx=[1,0,−1]D_x=[1,0,-1]Dx​=[1,0,−1] and its column version DyD_yDy​. All three filters are compared with SciPy using the same input and zero padding.

Four-loop implementation
def convolve_four_loops(input, kernel):
    # Zero padding
    # Have to account for non square kernels
    k_h = len(kernel)
    k_w = len(kernel[0])
    padding_len_h = (k_h - 1) // 2
    padding_len_w = (k_w - 1) // 2
    h = len(input) + 2 * padding_len_h
    w = len(input[0]) + 2 * padding_len_w
    padded_input = [[0] * w for _ in range(h)]
    for row in range(len(input)):
        for col in range(len(input[0])):
            padded_input[row + padding_len_h][col + padding_len_w] = input[row][col]

    # Convolution
    out_h = h - k_h + 1
    out_w = w - k_w + 1
    output = [[0] * out_w for _ in range(out_h)]
    for row in range(out_h):
        for col in range(out_w):
            total = 0
            for i in range(k_h):
                for j in range(k_w):
                    # Flip the kernel for convolution
                    total += padded_input[row + i][col + j] * kernel[k_h - 1 - i][k_w - 1 - j]
            output[row][col] = total
    return output
Two-loop implementation
def convolve_two_loops(input, kernel):
    # Zero padding
    k_h = len(kernel)
    k_w = len(kernel[0])
    padding_len_h = (k_h - 1) // 2
    padding_len_w = (k_w - 1) // 2
    h = len(input) + 2 * padding_len_h
    w = len(input[0]) + 2 * padding_len_w
    padded_input = [[0] * w for _ in range(h)]
    for row in range(len(input)):
        for col in range(len(input[0])):
            padded_input[row + padding_len_h][col + padding_len_w] = input[row][col]

    # Convolution
    out_h = h - k_h + 1
    out_w = w - k_w + 1
    output = [[0] * out_w for _ in range(out_h)]
    # Flatten to 1D to reduce the number of loops
    for i in range(out_h * out_w):
        row = i // out_w
        col = i % out_w
        total = 0
        for j in range(k_h * k_w):
            kernel_row = j // k_w
            kernel_col = j % k_w
            total += padded_input[row + kernel_row][col + kernel_col] * kernel[k_h - 1 - kernel_row][k_w - 1 - kernel_col]
        output[row][col] = total
    return output

Bells and whistles · Gradient orientation

The gradient direction is calculated with np.arctan2(I_y, I_x). The angles run from −π-\pi−π to π\piπ. Adding π\piπ and dividing by 2π2\pi2π normalizes the angles to 0–1, which is used as the hue in HSV. Different directions therefore get different colors.

Saturation is set to 1. The magnitude is divided by its maximum and square-rooted for brightness, so strong edges are bright and flat areas are dark. Converting HSV to RGB gives the color image below.

2.1 · Image sharpening

The image is blurred, then the blur is subtracted from the original to get the high frequencies. Adding the high frequencies back to the original image makes the overall image sharper. The sharpening amount is controlled by α\alphaα: 1 adds the detail once, and 2 adds it twice.

Let III be the original image and GGG the Gaussian filter. The blur is BBB, the high frequencies are HHH, and the sharpened image is SSS:

B=I∗G,H=I−B,S=I+αHB=I*G,\qquad H=I-B,\qquad S=I+\alpha HB=I∗G,H=I−B,S=I+αH

To combine this into one convolution, use the identity filter δ\deltaδ, which is 1 at its centre and 0 elsewhere. Convolving with it leaves the image unchanged: I∗δ=II*\delta=II∗δ=I. Substituting for HHH and collecting the filters gives:

S=I+α(I−I∗G)=(1+α)(I∗δ)−α(I∗G)=I∗[(1+α)δ−αG].\begin{aligned}S&=I+\alpha(I-I*G)\\&=(1+\alpha)(I*\delta)-\alpha(I*G)\\&=I*\bigl[(1+\alpha)\delta-\alpha G\bigr].\end{aligned}S​=I+α(I−I∗G)=(1+α)(I∗δ)−α(I∗G)=I∗[(1+α)δ−αG].​

The single unsharp mask filter is therefore (1+α)δ−αG(1+\alpha)\delta-\alpha G(1+α)δ−αG. The examples use a 13 × 13 Gaussian with σ=2\sigma=2σ=2.

Sharpening makes the edges stand out. In the Taj Mahal image, the construction on the left side of the building becomes more visible than in the original. In the building example, the cracks and wall textures also become clearer. Alpha 2 makes these details stronger, but the outlines look harsher than with alpha 1.
